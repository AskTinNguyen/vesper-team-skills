# Shot List Template

No standard notation exists across productions; make the template explicit and consistent so every collaborator reads it the same way.

## Columns

| # | Size | Lens | Height | Move | Eyeline | Action | Notes |
|---|------|------|--------|------|---------|--------|-------|
| 1 | MS | 35mm | Eye | None | A->B | Master, both enter | Room geography |
| 2 | OTS-B | 50mm | Eye | None | to A | Reaction to line | Cut in after line |
| 3 | CU-A | 85mm | Eye | Push 12" | to B | Deliver key line | Climax beat |
| 4 | ECU-A | 100mm | High eye | None | down | Circle prop | Insert |

Use these definitions:

- Size: ECU, CU, MCU, MS, MLS, LS, WS, insert.
- Lens: focal length or approximation; note compression/wide distortion intent.
- Height: ground/high eye/eye/low/bird.
- Move: static, pan, tilt, dolly/track, crane, handheld, push/pull.
- Eyeline: which character the subject looks at and where their look sits in frame.
- Action: the beat or line being covered.
- Notes: motivation, continuity trap, cutting intent.

## Best Practices

- Number panels in cutting order, not shoot order, so the editor and script supervisor can reconstruct the scene.
- When a scene's coverage spans multiple pages/sections, mark "part 1/2/3" in the corner of each page.
- Keep the master's screen direction reference on every page so later pages never flip the axis silently.
- On storyboards, place the character's first-name initial somewhere in the body so eyelines and identities stay clear.
- Storyboard panels must match the shot list order; previs/animatics extend the same discipline.

## Floor Plan Companion

For each shot list, include a floor plan with:

- Walls, doors, windows, furniture landmarks.
- Actor paths (start/end) as broken lines.
- Camera start and end positions (outline = start, solid = end).
- Pan arrows for moves, and moving-camera path arrows.
- The 180-degree axis drawn once so all shot directions are verifiable.
