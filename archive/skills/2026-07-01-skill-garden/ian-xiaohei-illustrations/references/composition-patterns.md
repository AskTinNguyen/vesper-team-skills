# Composition Patterns and Originality Rules

## Basic structure types

Choose one structure. Do not mix too many.

### Workflow

Good for: input -> processing -> output, content production, AI workflows, automation chains.

How to draw: input on the left, Xiaohei or a strange machine processing in the middle, output on the right, orange arrows for the main direction.

### System slice

Good for: information sources, filters, databases, renderers, agent-system components.

How to draw: show only 3-5 core modules; Xiaohei participates in one key action.

### Before / after contrast

Good for: chaos/order, manual/automatic, scattered/converged, anxious/stable.

How to draw: chaotic left side, stable right side, orange arrow in the middle. The character can be more exaggerated.

### Role state

Good for: user pain points, creator state, too many tools, information anxiety, stuck-to-running transition.

How to draw: 2-4 small states, each with one short label.

### Conceptual metaphor

Good for: content factory, information warehouse, mental black box, workflow machine, automatic daily report.

How to draw: one large weird object or machine, small amount of input, one output. It should be memorable.

### Method layering

Good for: methodology frameworks, system levels, capability stacks, content-system layers.

How to draw: stacked boxes, but not a formal pyramid; Xiaohei carries bricks or builds beside it.

### Map route

Good for: idea-to-launch, user path, content handoff path, learning path.

How to draw: one winding path, a few nodes, Xiaohei pulling a line or walking.

### Mini-comic panels

Good for: failure-to-success, real process, complaint, before/after usage change.

How to draw: 2-4 small scenes, one action per panel.

## Original metaphor method

Invent the metaphor from the current article every time. Do not copy old images.

### Three steps

1. Convert the abstract concept into a physical action: getting stuck, leaking, becoming heavy, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Convert the system structure into a low-tech object: broken machine, cardboard box, drawer, pipe, mailbox, strange dial, scale, well, ladder, odd workstation.
3. Make Xiaohei perform the action: not standing beside it, but stuck inside the machine, pulling the wrong wire, guarding a door, carrying, repairing, weighing, holding a ladder, recording, or pushing something into a strange device.

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, pipe, ball of string, gate, turntable, black box, puncher, noodle press, clothesline, odd workstation.
- Use only 1-2 objects. Do not fill the canvas.

### Xiaohei action pool

- Pull, carry, stuff, fish out, press, weigh, sew, cut, twist, guard, push, catch, dismantle, mark, recycle.
- The action must serve the core meaning. Do not be weird only for weirdness.

## Anti-copy rules

Do not open or copy `assets/examples/` by default. Those images are only for style calibration: line density, white space, color restraint, and how Xiaohei participates.

Unless the user explicitly says “copy this”, “recreate this composition”, or “edit this case”, do not directly reuse these old compositions:

- conveyor belt with two breakpoints
- Xiaohei pulling a judgment lever inside a content machine
- Xiaohei becoming a funnel that sorts traffic / trust / conversion
- Xiaohei cutting a material fish
- Xiaohei pulling a handoff path
- Xiaohei pulling three layers of information sources
- three Xiaohei figures holding a loudspeaker / building a bridge / opening a door
- Xiaohei stamping a copy toolbox
- Xiaohei holding a sign while looking at a common-pit path

For similar themes, invent a new metaphor. For example, “handoff path” does not always need a route; it could be Xiaohei tying the tail of a content piece to a door handle. “One fish, many uses” does not always need a fish; it could be Xiaohei pressing one paper ball into several shapes.
